# 💜 BTS-Themed Student Performance Analyzer

A beginner-friendly Data Science project using Python,
Pandas, scikit-learn, and Streamlit.

## Project Overview

This project explores the relationship between study hours,
attendance, and marks using a fictional student dataset.
It includes charts, summary statistics, and an interactive
Linear Regression demonstration.

## Features

- Student performance dataset
- Average marks and study hours
- Interactive charts
- Dataset explorer
- Marks prediction using study hours and attendance
- Streamlit dashboard

## Technologies Used

- Python
- Pandas
- scikit-learn
- Streamlit
- GitHub

## Run Locally

Install the required packages:

    pip install -r requirements.txt

Start the dashboard:

    streamlit run app.py

## Dataset and Limitations

The project uses six fictional practice records with
BTS-inspired labels. These are not real academic records.

The model is for learning only. Six records are not enough
to make reliable real-world academic predictions.
